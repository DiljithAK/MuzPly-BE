# Contributing Guide

## Workflow

1. Create or activate the local virtual environment.
2. Install dependencies from `requirements.txt`.
3. Make focused changes in the appropriate layer.
4. Run tests before sharing changes.
5. Update docs when behavior or setup changes.

## Pull Request Checklist

- Code follows the existing project structure
- New behavior includes tests where practical
- Documentation is updated
- Temporary-file cleanup behavior remains intact
